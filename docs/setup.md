# Setup Guide

## Prerequisites
- Node.js 18+
- npm

## Installation
```bash
cd luna-careers
npm install
```

## Environment Variables
Copy `.env.local.example` to `.env.local` and fill in:
```
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## Development
```bash
npm run dev
```

## Build
```bash
npm run build
```
